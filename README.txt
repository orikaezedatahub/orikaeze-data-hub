# Orikaeze Data Hub website files

This package contains the refreshed static website:
- index.html — homepage
- data.html — data order preview
- airtime.html — airtime order preview
- about.html — about page
- assets/style.css — styling
- assets/app.js — front-end form behaviour

## Important
This is a front-end preview only. It does not collect payments, create real orders, deliver airtime/data, or store customer accounts. Do not add VTU API keys or payment secrets to these files or to a public GitHub repository.

A secure server-side backend, payment gateway integration, approved VTU API account, webhook validation, database, and end-to-end testing are required before live transactions.
